# Diagramas PlantUML do VCOS

Esta pasta documenta a arquitetura atual do projeto VCOS com diagramas PlantUML.

- `c4-model.puml`: visão C4 em níveis de contexto, contêineres e componentes.
- `use-case-diagram.puml`: principais interações da artesã/responsável com o app.
- `class-diagram.puml`: classes centrais de domínio, estado, persistência e sincronização.

Para renderizar localmente:

```bash
plantuml docs/plantuml/*.puml
```
